RoI pooling vs RoIAlign

D2-02 · section 5 All labs

One proposal (blue), one feature map, two ways to cut out a fixed-size tile. Drag or resize the box on either map, hover a bin or a sample point, and nudge the box by a tenth of a cell.

Try this - predict first, then check

  1. Click 0.1 cell ▶ five times. In the centre bin, which output follows the box and which jumps?
    why

    RoI pooling only sees the rounded box: until an edge crosses a half cell it reads the same cells, then a whole column changes at once (the orange staircase in the sweep plot). RoIAlign's samples move with the box and their bilinear weights change continuously (blue curve). A staircase has zero gradient almost everywhere: box and mask heads train better on RoIAlign.

  2. Switch the stride from 16 to 32. How many image pixels can RoI pooling's input be off?
    why

    Rounding moves each box edge by up to half a cell, and the integer bins add up to another cell: with the default box 13 px and 32 px at stride 32. Tolerable for "is this a person?", not for a 28 x 28 mask that must follow the outline. RoIAlign never rounds, at any stride.

  3. Choose 7x7. How many cells does a RoI pooling bin read when the box is only ~5 x 4 cells?
    answer

    Bins smaller than a cell still read whole cells (1 or 2 per side), so neighbouring bins read the same cells (the box under the outputs counts them) and copy the same maximum: the 7x7 output is blocky. RoIAlign gives every bin its own sample positions.

  4. Pick single peak. How many pooled outputs show 9.0? How close does RoIAlign get?
    why

    Four of the nine pooled outputs are 9.0: max pooling copies the peak at full height into every bin that touches its cell. RoIAlign's largest output is about 4: it averages interpolated values, so the peak is shared out smoothly and fades with distance.

  5. Set sampling ratio 1 and hover a sample. When does a sample return exactly one cell's value?
    answer

    Only on a cell centre, where one weight is 1. Elsewhere it blends four cells with weights (1-ly)(1-lx), (1-ly)lx, ly(1-lx), ly lx, which sum to 1. More samples per bin (2 x 2 by default) cover more of the bin.
