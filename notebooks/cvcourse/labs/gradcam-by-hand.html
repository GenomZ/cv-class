Grad-CAM by hand

D1-04 · section 6 All labs

Grad-CAM is a weighted sum of feature maps, L = ReLU(Σ_k α_k A^k). Here eight hand-made maps of the photo play layer4's channels and α_k plays one class's averaged gradient. Set the weights, hover any map.

weighted sum

With a global-average-pool + linear head, ∂y/∂A^k is the same in every cell (w_k / hw), so α_k is the class weight and Grad-CAM equals CAM (Zhou et al. 2016); y is then the mean of the sum. Deeper heads make α_k a true average.

Try this - predict first, then check

  1. Switch from face to uniform. The eight feature maps do not change at all. Why does the heat map move?
    why

    Only the α_k changed. The feature maps are computed once for the image and are the same for every class; the class enters Grad-CAM only through the gradients, pooled into one weight per channel. That is what makes the map class-specific.

  2. Turn the ReLU off. Which regions now look half-hot, and why is that misleading?
    why

    Without the ReLU, min-max scaling maps the most negative evidence to 0, so regions that are simply irrelevant (sum ≈ 0) appear warm. Negative values are evidence against this class (often for another one); the ReLU keeps only what increases y^c.

  3. Set the grid to 4 x 4, then to 32 x 32. Why are real Grad-CAM maps always smooth blobs?
    why

    The map is only as fine as the feature map it weights. ResNet-50's layer4 on a 224 px image is 7 x 7: every cell covers 32 x 32 pixels. Bilinear upsampling makes it smooth but adds no detail. Grad-CAM on layer3 (14 x 14) is sharper but less semantic.

  4. Set every α to 0 except centre. The map highlights the face. Is that an explanation?
    answer

    No: the centre map ignores the image, so you would get the same blob for any photo - here it only happens to fall on the face. A plausible-looking map can carry no information about the content (Adebayo et al. 2018); this is why the notebook measures the evidence against the pet mask instead of trusting a few nice pictures.
